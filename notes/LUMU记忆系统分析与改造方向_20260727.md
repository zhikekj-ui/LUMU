# LUMU 记忆系统分析与改造方向
> 2026-07-27 对话记录

---

## 一、当前架构评估

### 已有的能力

| 组件 | 功能 | 状态 |
|------|------|------|
| `IntelligentMemory` | 5层记忆架构（工作/情景/语义/程序/长期），艾宾浩斯遗忘曲线，TF-IDF检索，记忆关联图谱 | ✅ 可用 |
| `SemanticMemory` | 向量嵌入 + 余弦相似度语义搜索 | ✅ 可用 |
| `SelfLearningEngine` | 交互记录→经验提取→策略优化→元认知反思 | ✅ 可用 |
| `PreferenceExtractor` | LLM自动分析对话提取用户偏好 | ✅ 可用 |
| `ContextProfile` | 用户画像、项目、系统、任务、会话历史积累 | ✅ 可用 |

### 三块碎片问题

**问题1：多存储层各自为战，没有形成闭环**
- `IntelligentMemory` → JSON 存储
- `SemanticMemory` → SQLite
- `MemoryManager` → SQLite（另一个）
- `SelfLearningEngine` → 写入 MemoryManager 的 SQLite
- 同一句话可能在 3-4 个地方存储 3-4 份不同表示，彼此无关联

**问题2：没有用户可见的「我知道你什么」面板**
- 所有偏好、记忆、画像都在幕后
- 用户不知道 AI 记住了什么
- 错误的推断无法被用户纠正

**问题3：记忆没有时间衰减，存了就永远等权**
- `semantic.py` 搜索评分：`score = sim * (0.7 + 0.3 * importance) + access_count * 0.01`
- 无时间因子 → 一年前的记忆和今天的记忆搜索权重相同
- 记忆无限膨胀，旧信息干扰新判断

## 二、改造方案

### 方案1：统一记忆总线

```
用户输入 → 语义嵌入 → SemanticMemory (主存储)
              ↓
         IntelligentMemory (逻辑分层，读语义存储做查询)
              ↓
         SelfLearningEngine (异步分析，提取偏好/教训)
              ↓
         ContextProfile (缓存最新画像)
```

让 `SemanticMemory` 成为唯一的事实存储层，其他层基于它构建，消除数据碎片。

### 方案2：记忆透明度界面

在 LUMU 前端加 `/memory` 页面，分级展示：

| 置信度 | 标签 | 示例 |
|--------|------|------|
| ≥ 0.8 | **我确定知道的** | 「你是系统管理员」 |
| 0.4 ~ 0.8 | **我正在学习的** | 「你可能喜欢简洁的回答」 |
| < 0.4 | **我猜测的** | 「你可能偏好 Python」 |

每条后面跟「纠正」「删除」「确认」按钮。每周自动生成「我对你的了解报告」。

### 方案3：时间衰减 + 主动遗忘

**搜索评分改造**（参考实现）：
```python
hours_elapsed = (now - last_accessed).total_seconds() / 3600
decay = math.exp(-hours_elapsed / (30 * 24))  # 30天半衰期
final_score = similarity * (0.4 + 0.6 * decay) * importance
```

**后台定时清理任务**：
- 30 天未访问 + 重要性 < 0.3 → 归档（不删除，但不出现在搜索结果中）
- 90 天未访问 + 重要性 < 0.5 → 删除（除非用户标记了「永久保留」）

## 三、自我评估

**得分：8.5 / 10**

| 维度 | 评分 | 说明 |
|------|------|------|
| 源码理解 | ✅ | 读代码指出 `semantic.py` 缺少时间衰减 |
| 方案克制感 | ✅ | 不是推倒重来，而是加三层胶水 |
| 可执行性 | ✅ | 给了伪代码、阈值、设计思路 |
| 主动问询 | ❌ | 从未主动问「我哪里让你不满意？」 |
| 跨会话记忆联动 | ❌ | 没有在回答中自然引用过往对话中的偏好 |
| 系统自检 | ❌ | memory.db FTS5 索引损坏未被主动发现 |

**改进方向**：
1. 每 3-5 次交互后主动询问「我最近的表现需不需要调整？」
2. 回答前自觉检索过往相关的偏好和决策，在回答中自然引用
3. 每周做一次系统组件健康扫描，提前发现问题
